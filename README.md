# Программный комплекс «Водоканал-Сервис»
## Учёт абонентов, приборов учёта и начислений платежей водоканала

Программный комплекс разработан для производственной практики по специальности **09.02.07 «Информационные системы и программирование»** (КГБПОУ «Канский технологический колледж»).
Приложение автоматизирует абонентский учёт, регистрацию приборов учёта холодной и горячей воды (ХВС/ГВС), приём ежемесячных показаний, автоматический расчёт расхода и начислений по тарифам, проведение платежей, печать квитанций и аналитическую отчётность.

---

### 1. Архитектура и стек технологий
- **Платформа:** .NET Framework 4.8, WPF (Windows Presentation Foundation), C# 7.3.
- **Архитектурный шаблон:** MVVM (Model-View-ViewModel) с собственными легковесными классами `ObservableObject`, `RelayCommand` и `AsyncRelayCommand` без сторонних зависимостей.
- **Доступ к данным:** Прямой ADO.NET (`IDbConnection`, `IDbCommand`, `IDbTransaction`) с полной параметризацией SQL-запросов и транзакционной целостностью.
- **СУБД:** Встроенная автономная база данных **SQLite** (файл `data.db`) с поддержкой миграции схемы на **MS SQL Server 2014+** (в папке `Database/mssql`).
- **Библиотека данных:** `System.Data.SQLite 1.0.118` из локальной папки `/lib` (без обращения к NuGet).
- **Безопасность:** Хэширование паролей пользователей с использованием криптостойкого алгоритма PBKDF2 (`Rfc2898DeriveBytes`, 10 000 итераций, криптографическая соль 16 байт).

### 2. Учётные записи для проверки системы

При первом запуске базы данных автоматически формируются учётные записи сотрудников и абонентов. Окно входа оснащено кнопками быстрого заполнения реквизитов:

| Роль в системе | Логин | Пароль | ФИО / Назначение |
| :--- | :--- | :--- | :--- |
| **Администратор** | `admin` | `admin` | Администратор системы (полный доступ, тарифы, БД, пользователи) |
| **Оператор** | `operator` | `operator` | Михайлова Е.С. (картотека абонентов, приборы, ввод показаний, отчёты) |
| **Кассир** | `kassir` | `kassir` | Петрова О.В. (приём оплат, история платежей, квитанции, кассовая сводка) |
| **Абонент** | `100245` | `user` | Соколова Нина Петровна (личный кабинет: баланс, подача показаний, печать квитанции) |

> **Примечание по учетным записям абонентов:** При заведении нового абонента в картотеку ему автоматически создаётся учётная запись личного кабинета (логин равен номеру лицевого счёта, пароль по умолчанию `user`). Редактировать учётные данные и блокировать доступ можно в разделе «Система и БД».

### 3. Основные функциональные модули

1. **Абоненты:** Картотека абонентов (физические лица и организации), быстрый поиск с задержкой 300 мс (по лицевому счёту, ФИО и адресу), фильтрация по категории и наличию задолженности. Отображение баланса, начислений и прикреплённых приборов учёта.
2. **Приборы и показания:** Учёт счётчиков воды (ХВС/ГВС), даты установки и опломбировки, ввод ежемесячных показаний в м³ (в базе хранятся в литрах). Мгновенный расчёт расхода и стоимости по действующему тарифу. Автоматическая валидация: показание не может быть меньше предыдущего, контроль разового ввода в расчётном месяце.
3. **Касса и платежи:** Приём оплаты наличными, банковской картой или банковским переводом с привязкой к абоненту. Просмотр истории и формирование платёжного документа (квитанции) формата `FlowDocument` с возможностью прямой печати на принтере.
4. **Тарифы:** Сетка действующих тарифов с датами вступления в силу. Запрет на редактирование старых тарифов для сохранения корректности исторических расчётов.
5. **Аналитика и отчёты:**
   - *Реестр должников (сложный аналитический запрос А):* CTE-агрегация начислений и оплат, расчёт задолженности, ранжирование с помощью оконной функции `RANK()`.
   - *Подозрительный расход (сложный аналитический запрос Б):* Выявление аномалий и аварийных утечек с расчётом скользящего среднего расхода за 3 предшествующих месяца (`ROWS BETWEEN 3 PRECEDING AND 1 PRECEDING`).
   - *Помесячная динамика потребления:* Таблица и визуальная столбиковая диаграмма на `Canvas` раздельно по ХВС и ГВС.
   - *Сводка платежей:* Группировка поступлений по способам оплаты.
   - *Экспорт:* Выгрузка любого сформированного отчёта в файл CSV (разделитель `;`, кодировка UTF-8 с BOM для корректного открытия в Excel).
6. **Система и база данных:**
   - Отображение текущего пути к файлу базы данных и его размера на диске.
   - Кнопка быстрого открытия папки с БД в Проводнике Windows.
   - Кнопка выбора/смены подключаемого файла SQLite.
   - Создание и восстановление резервных копий (`.db`).
   - Переключатель автозаполнения тестовыми данными при первичном создании базы.
   - Кнопка «Убрать тестовые данные» (удаление демонстрационных абонентов, приборов и платежей с сохранением справочников и сотрудников).
   - Управление сотрудниками и учётными записями.
7. **Личный кабинет абонента:**
   - Персональная карточка потребителя и лицевого счёта.
   - Отображение текущей задолженности, начислений и оплат.
   - Форма передачи текущих показаний счётчиков воды.
   - Просмотр истории переданных показаний и оплат.
   - Печать платёжной квитанции за текущий месяц.

### 4. Инструкция по сборке и запуску

1. Открыть решение `VodokanalManager.sln` в **Visual Studio 2019** (или новее).
2. Выбрать конфигурацию **Release | Any CPU**.
3. Выполнить команду **Сборка -> Пересобрать решение** (`Ctrl+Shift+B`).
4. Готовый исполняемый файл находится в каталоге `VodokanalManager\bin\Release\VodokanalManager.exe`.
5. Для автономной работы на любом ПК достаточно скопировать содержимое папки `bin\Release` (включая подпапки `x86` и `x64` с `SQLite.Interop.dll`). Установка дополнительного ПО и права администратора не требуются.
